# ☕ cafe-landing

동네 카페 "솜솜 카페"를 소개하는 **간단한 랜딩 페이지**입니다.
HTML과 CSS만으로 만들었고, 별도 설치나 빌드 없이 바로 열어볼 수 있습니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일 (베이지·브라운 톤, 모바일 대응 반응형) |
| `README.md` | 이 문서 |

## 사용 방법

1. 이 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다.

## 수정 방법

- 카페 이름, 메뉴, 가격, 주소, 영업시간은 `index.html`에서 바꿀 수 있습니다.
- 색상은 `style.css` 맨 위의 `:root` 변수(`--brown`, `--cream`, `--accent`)로 조절합니다.

> 주소·전화번호·메뉴 정보는 예시 내용입니다. 실제 정보로 교체해서 사용하세요.

## 만든 이유

AI 에이전트 수업 실습용 예제입니다.
