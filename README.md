# ☕ cafe-landing

가상의 카페 **Morning Brew**의 간단한 랜딩 페이지 예제입니다.
AI 에이전트 수업 실습으로 만들었으며, 별도 빌드 없이 HTML/CSS만으로 동작합니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 랜딩 페이지 본문 (메뉴, 카페 소개, 오시는 길) |
| `style.css` | 페이지 스타일 (반응형 카드 레이아웃) |

## 페이지 섹션

- 상단 내비게이션
- 히어로 영역 (메인 문구와 버튼)
- 대표 메뉴 카드 4종
- 카페 소개
- 오시는 길 / 영업시간
- 푸터

## 실행 방법

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/somin-c/cafe-landing.git
   ```
2. `index.html` 파일을 브라우저(Chrome 등)에서 엽니다.
